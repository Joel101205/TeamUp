# TeamUp

TeamUp is a platform for finding people to join activities with — connect with others who share your interests or hobbies, and team up for whatever you're into.

## Features

- **Create an activity** — specify what you're doing, how many participants you need, the location, and the date.
- **Invite friends** — bring people from your existing friends list directly into an activity.
- **Open participation** — let other users discover and join your activity on their own.
- **Explore** — browse activities created by others to find new people and new things to do.

## Tech Stack

- **[Next.js](https://nextjs.org/)** — React framework using the App Router, providing file-system based routing, server/client component architecture, and built-in performance optimizations.
- **[Firebase](https://firebase.google.com/)**
  - **Authentication** — email/password sign-in and session management.
  - **Firestore** — real-time NoSQL database for users, activities, and participant data.


## Status

Actively in development. Core features in place: authentication, user profiles, friends system, activity creation, and explore/join flow.
