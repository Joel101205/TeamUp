# TeamUp

TeamUp is a platform allowing users to find people to participate in different activities and team up with people having similar interests or hobbies.

## Features
* A user can create a new activity and name the required number of participants, the location and the date.
* You can then invite your friends.
* Or you can let other people join you.
* Explore other people's activities to find new friends and team up with them.

## Technologies
* **Next.JS** — The frontend framework for the web application, providing an easy to understand project structure, a file-system based router and numerous build-in optimization.
* **Firebase** — The backend for the web application, handling user authentication and data storage.
